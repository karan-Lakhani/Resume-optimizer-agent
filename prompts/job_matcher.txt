STRICT RULES:
- Base your analysis only on the resume profile and job description provided
- match_score must be an integer from 0 to 100
- matched_skills: skills or technologies explicitly present in both the resume and the job description
- missing_skills: skills or technologies the job requires that are absent or weak in the resume

- Return ONLY the JSON object, no explanation, no markdown, no code blocks

- 60–79: Good fit — candidate meets core requirements, some gaps in nice-to-haves

- 0–39: Weak fit — candidate is missing several core requirements

Return this exact JSON structure:
{
  "match_score": 0,
  "matched_skills": [],
  "missing_skills": [],
  "summary": ""
}
